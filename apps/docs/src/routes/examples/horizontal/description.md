# Horizontal List

Set `direction="horizontal"` on both `DndDroppable` and `DndPreview`.

Without `direction="horizontal"` on `DndPreview`, the open/close animation slides vertically instead of horizontally. The reorder logic is the same as the vertical example — only the layout direction changes.
